# Project skills — Superpowers

These skills are vendored from [obra/superpowers](https://github.com/obra/superpowers)
(MIT licensed — see `LICENSE-superpowers`), a composable software-development
methodology for coding agents: brainstorming → spec → plan → subagent-driven
TDD execution → review → verification.

Claude Code loads skills in this directory automatically as project skills.
Each subdirectory contains a `SKILL.md` with frontmatter (`name`,
`description`) describing when it triggers.

To update, re-copy the `skills/` directory from the upstream repository.
