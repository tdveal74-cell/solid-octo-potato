# design-sync notes — quiet-operator

- This is a Next.js app, not a published package. Library entry fields
  (`main`/`module`/`types` → `dist/`) were added to package.json solely so the
  converter's `.d.ts` discovery works; `npm run build:lib` (tsc + a CSS concat
  script) produces `dist/`. Run it before the converter — the converter reads
  `dist/index.js` + `dist/index.d.ts` + `dist/styles.css`.
- `dist/styles.css` is generated by `scripts/build-css.mjs`
  (components.css with tokens.css inlined). `cfg.cssEntry` points at it because
  the converter copies the cssEntry file verbatim — a relative `@import` inside
  it would dangle in the bundle.
- Dark-theme DS: previews are illegible without `cfg.provider = Surface`
  (the library's ink root canvas). Keep the provider set; a white card means the
  provider was dropped.
- Playwright: install `playwright@1.56.0` in `.ds-sync/` — the environment's
  cached chromium build is 1194 (`/opt/pw-browsers`); newer playwrights pin
  newer builds and fail to launch.

## Known render warns

- `[FONT_MISSING] "Cascadia Code"` — intentional. The brand's type stacks are
  system fonts (Georgia / Helvetica Neue / SF Mono, Cascadia Code, Menlo,
  monospace); there are no font files to ship and the generic fallbacks always
  resolve. Not a substitution to fix.

## Re-sync risks

- `dist/` is gitignored and machine-built: a re-sync on a fresh clone must run
  `npm ci` then `npm run build:lib` first, or discovery finds zero components.
- Preview data (council names, audit rows) is inlined in
  `.design-sync/previews/*.tsx`; if `src/lib/council` naming changes, previews
  keep rendering the old names — cosmetic drift only, not detected by any gate.
- `cardMode: column` overrides exist for Stat and RangeField; new wide preview
  exports on other components may need the same treatment (validate flags them).
- The app's Tailwind layer maps utilities onto the same tokens via
  `@theme inline` in `src/app/globals.css` — token renames must land in
  `src/components/tokens.css` (single source) or app and DS drift apart.
