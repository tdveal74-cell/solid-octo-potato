## Law

**Reads flow. Writes wait.**

| Mode | Agent may | Agent must not |
|------|-----------|----------------|
| Read | Repos, docs, logs, status | — |
| Propose | PRs, copy, pipeline diffs | Silent merge |
| Write | Only after explicit approve | Deploy, secrets, n8n activate without OK |
